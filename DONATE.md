# Support this project

`updown-5m-predictor` and the dataset
[`Fahri-5/updown-5m-polymarket-raw`](https://huggingface.co/datasets/Fahri-5/updown-5m-polymarket-raw)
are free and open (code and data are published openly; the dataset is CC0).
Running the 24/7 collection pipeline costs money for a server and cloud
storage. If this work is useful to you, you can help cover those costs.

Donating is entirely optional. The project stays free whether or not anyone
donates.

## What donations are used for

- Server hosting (VPS) for the 24/7 data collector
- Cloud storage and bandwidth for raw data and backups

Any surplus stays in the project wallet and goes toward future
infrastructure costs. Donations are not used to fund trading.
